# Data Classification Using AI

## Project Overview
This project is a basic machine learning classification system built using the Iris dataset.

The model is trained to classify flower species based on their features using the K-Nearest Neighbors (KNN) algorithm. The project demonstrates the fundamental workflow of supervised learning including data preprocessing, training, testing, evaluation, and visualization.

The project was created to practice machine learning concepts and model evaluation techniques in Artificial Intelligence.

## How the System Works

1. Load the Iris dataset.
2. Scale the data using StandardScaler.
3. Split the dataset into training and testing sets.
4. Train the KNN classification model.
5. Test the model and calculate performance metrics.
6. Display visualizations and classification results.

---

## Features
- Uses supervised learning
- Applies KNN classification
- Finds the optimal K value
- Displays Accuracy Score
- Displays F1 Score
- Displays Confusion Matrix
- Generates visual graphs
